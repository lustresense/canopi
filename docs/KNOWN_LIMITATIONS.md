# Known limitations

- Internal 0.0.1 only; no beta/stable claim or ready installer.
- OAuth authentication is a stub.
- Native SmartRouter is incomplete.
- Cloud Light is broken.
- A missing Rust `Deserialize` import remains unresolved.
- Windows compilation and end-to-end acceptance are unverified for this source snapshot.
- Browser preview cannot validate Tauri/native engine integration.
- The historical 122-test baseline includes source-contract/regex checks; it is not readiness evidence. Current counts must come from execution against the exact commit.
- No verified installer lifecycle, production-provider, signed release, cross-platform support or current performance claim is made by this publication.

Publication curates source and documentation; it does not silently repair these application defects. Consult `SOURCE-MANIFEST.json` for source identity, not runtime acceptance.
