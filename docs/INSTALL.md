# Installation

There is no verified ready-to-install binary attached to this source snapshot. Internal version 0.0.1 is not a beta/stable release. Do not infer installability from a public source commit, old artifact name or passing source tests.

Developers may follow [BUILD.md](BUILD.md) on a disposable Windows machine. Review the pipeline before execution: it can perform silent install/uninstall verification. Intended target is Windows; current Windows compilation and installer acceptance are unverified. No macOS/Linux desktop support claim is made.

Only recommend an installer after its exact source/engine provenance, checksums, signature policy and actual platform tests have been verified. No download link is supplied until such an artifact exists.

The installer source implements keep/delete-data handling. Treat deletion as irreversible; back up app-owned data before experiments. No retention guarantee is established without testing the actual installer.
